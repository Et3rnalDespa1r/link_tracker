# LinkTracker

**LinkTracker** – Telegram-бот, который отслеживает изменения на веб-страницах и оперативно информирует пользователя о них.

Это шаблон проекта, который взят за основу для разработки интеллектуального агрегатора уведомлений.
Полезную для разработки проекта информацию можно найти в файле [HELP.md](./HELP.md).

---

## 🛠 Инструкция для ассистента (Запуск и проверка)

В рамках первого домашнего задания реализован базовый каркас Telegram-бота (сервис `bot`), настроена типобезопасная конфигурация, структурное логирование и диспетчеризация команд `/start` и `/help`.

### 1. Настройка окружения
Для запуска бота необходимо создать конфигурационный файл:
1. Создай файл `.env` в корневой директории проекта (файл добавлен в `.gitignore`).
2. Добавь в него токен вашего тестового бота:
   ```env
   APP_TELEGRAM_TOKEN=токен_бота
   ```
### 2. Запуск проекта
В корне проекта выполни команду:
    ```
    go run cmd/bot/main.go
    ```
### 3. Запуск автотестов
Для запуска автотестов выполни команду:
    ```
    go test -v ./...
    ```
### 4. Функционал
Бот поддерживает автоматическую регистрацию команд в меню Telegram.
 * /start — Начало работы
 * /help — Список команд
 * Неизвестная команда — Бот возвращает сообщение об ошибке.
